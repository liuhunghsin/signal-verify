01 · Signal Integrity

訊號完整性基礎

訊號完整性（SI）問的是：發送端送出的 0 和 1，到了接收端還分不分得清楚。速度愈快，走線就愈不像一條「導線」，而愈像一個會反射、會損耗、會互相干擾的通道。

為什麼需要訊號驗證

模擬只能反映模型裡有的東西。實際的板材參數、製程公差、連接器、線材、電源雜訊和溫度，都會讓量產板子與模擬結果有落差。訊號驗證就是用儀器實際量測，確認每個介面在規格要求下仍有足夠的裕度（margin），並在出問題時找出原因。

上升時間決定頻寬

決定一個數位訊號「有多高頻」的，主要是邊緣的上升時間，而不是時脈頻率。上升時間通常指 10% 到 90% 的時間。

BW ≈ 0.35 / tr　　fknee ≈ 0.5 / tr

例如 100 MHz 時脈，但邊緣只有 50 ps，訊號的有效頻寬約 7 GHz。這也是為什麼「低速」介面換了更快的晶片後，也可能突然出現振鈴和串音問題。

傳輸線與特性阻抗

當走線的傳遞延遲和上升時間相當時，就要當成傳輸線看待。常用經驗法則：走線延遲超過上升時間的約 1/6，就需要控制阻抗。FR-4 板材內層走線的傳遞延遲約為 6–7 ps/mm（約 150–180 ps/inch）。

特性阻抗 Z0 由線寬、介電層厚度、介電常數與銅厚決定。常見目標值：

用途常見目標阻抗
一般單端高速線50 Ω
USB 差動對90 Ω
PCIe 差動對85 Ω（亦常見 100 Ω）
HDMI、DisplayPort、乙太網路差動對100 Ω
DDR 資料線（單端）約 40–50 Ω

實際目標值以晶片廠設計指南與板廠疊構為準，製程公差通常為 ±10%。

反射

訊號遇到阻抗改變的地方，就會有一部分能量反射回去。過孔（via）、連接器、焊墊、分支走線（stub）和端接不當都是常見來源。

Γ = (ZL − Z0) / (ZL + Z0)

Γ 為正時反射同向，波形會出現上凸的台階；為負則出現下凹。開路 Γ = +1，短路 Γ = −1，匹配時 Γ = 0。反射來回疊加後，就成了示波器上看到的振鈴（ringing）。

損耗

通道損耗隨頻率升高而增加，主要有兩種：

  • 導體損耗：高頻電流集中在銅箔表面（趨膚效應），加上銅箔表面粗糙度，等效電阻變大。
  • 介質損耗：與板材的損耗因子（Df）成正比，頻率愈高愈明顯。高速設計常改用低損耗板材。

高頻衰減得比低頻多，邊緣就會變鈍，前一個位元的能量拖進後一個位元，形成符號間干擾（ISI）。這是高速介面眼圖閉合的頭號原因，也是需要等化器的理由。損耗通常用奈奎斯特頻率（符號率的一半）上的插入損耗 dB 值來描述。

串音

相鄰走線之間透過電容和電感耦合，互相干擾。

  • 近端串音（NEXT）：在干擾源發送端那一側量到的雜訊。
  • 遠端串音（FEXT）：沿著走線方向傳到接收端的雜訊。帶狀線（stripline）的 FEXT 通常比微帶線（microstrip）小。

常見對策：加大線距（3W 原則：中心距至少三倍線寬）、縮短平行長度、在高速差動對之間放地線或地孔、讓高速線走內層。

差動訊號

高速序列介面幾乎都用差動訊號：接收端只看 P 與 N 的差值，共模雜訊會被抵消，輻射也較低。但 P/N 兩條線的長度差（skew）或不對稱佈線，會把差動訊號轉換成共模雜訊（模態轉換），反而讓眼圖變差、EMI 增加。

電源完整性的影響

多個輸出同時切換時，電源與地的瞬間壓降（同步切換雜訊，SSN）會直接調變訊號振幅與邊緣時間。電源漣波也會透過 PLL 變成抖動。所以量到的抖動特別大時，常常要回頭查電源。

02 · Eye Diagram & Jitter

眼圖與抖動

眼圖把大量位元波形疊在同一個畫面上，一次看出振幅夠不夠、時序準不準。抖動則是時間軸上的不確定性，決定眼睛的寬度。

眼圖怎麼形成

示波器擷取一長段資料，用恢復出來的時脈（CDR）把波形切成一個個 UI（Unit Interval，一個位元或符號的時間），再全部疊在一起。例如 10 Gb/s NRZ 的 1 UI = 100 ps。

眼睛張得愈開，接收端愈容易判斷。眼睛上下被壓扁是振幅問題（損耗、雜訊、反射），左右被擠窄是時序問題（抖動、ISI）。

常見量測參數

參數意義
眼高 Eye Height眼睛中央可用的電壓開口，通常以特定 BER 外推。
眼寬 Eye Width眼睛可用的時間開口，等於 1 UI 減去總抖動。
振幅 / 共模電壓差動振幅與 P、N 的平均電壓。
上升 / 下降時間邊緣速度，常用 20%–80% 或 10%–90%。
交叉點 Crossing上升與下降邊緣交會的高度，偏離 50% 代表工作週期失真。

遮罩測試

規格會定義一個眼圖遮罩（mask），通常是中央的菱形或六角形，加上上下禁止區。任何波形取樣點碰到遮罩就算失敗。許多新版規格改在套用參考等化器後，於指定 BER 下檢查眼高、眼寬。

抖動分類

TJ 總抖動 Total Jitter ├─ RJ 隨機抖動 Random 高斯分布、無上界，用 rms 描述 └─ DJ 確定性抖動 Deterministic 有上界，用峰對峰描述 ├─ DDJ 資料相依抖動 與資料型樣有關 │ ├─ ISI 符號間干擾 通道損耗、反射 │ └─ DCD 工作週期失真 上升下降不對稱、偏壓 ├─ PJ 週期性抖動 電源漣波、時脈耦合、展頻 └─ BUJ 有界不相關抖動 串音等

RJ 來自熱雜訊等隨機過程，理論上沒有上限，量得愈久最大值就愈大，所以不能直接用峰對峰值比較，要換算到指定的位元錯誤率（BER）。

TJ(BER) = DJδδ + 2Q(BER) × RJrms
目標 BER2Q 係數
1e-911.996
1e-1214.069
1e-1515.883

DJδδ 是雙狄拉克模型下的 DJ，通常比直接量到的 DJ 峰對峰值小。不同量測軟體的分解演算法可能給出不同的 RJ / DJ，比較數據時要用同一套工具。

浴缸曲線

把取樣點在 UI 內左右移動，畫出每個位置的 BER，就得到像浴缸剖面的曲線。在目標 BER 的高度切一刀，兩邊的距離就是該 BER 下的眼寬。

PAM4 與多階調變

當速度高到通道損耗吃不消，就改用一個符號帶多個位元。PAM4 有 4 個電壓階、每個符號 2 個位元，符號率只要 NRZ 的一半，但眼圖變成上下三個眼睛。

  • 訊雜比較差，通常要搭配前向錯誤更正（FEC），允許較高的原始 BER。
  • 多了階位線性度（RLM）等量測項目，確認四個電壓階是否等距。
  • PCIe 6.0、7.0 與 100G/200G 每通道乙太網路採用 PAM4；USB4 v2 與 GDDR7 採用 PAM3。

時脈恢復與抖動轉移

接收端的 CDR 會追蹤低頻抖動，所以低頻的漂移不會真的造成錯誤。為了讓量測結果貼近真實接收器，規格會指定「參考 CDR」的迴路頻寬，示波器以同樣的頻寬恢復時脈再量抖動。CDR 設定錯誤，量到的抖動可能差很多，這是新手最常踩的坑之一。

03 · Instruments

量測儀器與方法

量測本身也是通道的一部分。儀器頻寬、探棒、治具和接線方式，都會改變你看到的波形。

示波器

頻寬

示波器頻寬不足會讓邊緣變慢、眼圖看起來比實際差。量測到的上升時間約為：

tr,量測 ≈ √( tr,訊號² + tr,示波器² + tr,探棒² )

經驗上，示波器頻寬取訊號頻寬的 3 到 5 倍，上升時間誤差約在 5% 到 2% 之內。做相容性測試時，各規格的測試程序（CTS / MOI）會明確指定最低頻寬與濾波設定，一律照規定。

取樣率與記錄長度

  • 即時取樣率建議至少為頻寬的 2.5 倍。
  • 記錄長度要夠長，才能收集足夠的位元做抖動分解與低頻抖動分析，一般至少上百萬個 UI。
  • 測差動訊號時先做通道間 deskew，確保 P、N 兩路時間對齊。

探棒

探棒接上去就會對電路造成負載，尤其是電容性負載會在高頻降低阻抗。

  • 地線越短越好：長地線的電感會和探棒電容形成共振，產生不存在的振鈴。高頻量測請用彈簧地針或焊接式探頭。
  • 差動探棒：量差動訊號時直接取 P−N，共模抑制較好。
  • 量測點位置：理想上要量接收端的腳位，但實際常只能量到過孔或測試點，這時量到的是含反射的波形，判讀時要考慮。
  • Interposer：DDR 這類 BGA 封裝的介面，常用插在記憶體顆粒下方的轉接板把訊號引出來。

治具、去嵌入與嵌入

序列介面的相容性測試通常透過官方或協會提供的測試治具，用 SMA 線直接接到示波器。治具本身的損耗會被扣掉，這叫去嵌入（de-embedding），需要治具的 S 參數檔。

反過來，有些規格要求在量到的波形上「加上」一段參考通道，模擬最差長度的走線或線材，再看眼圖是否仍能張開，這叫嵌入（embedding）。

TDR：看阻抗沿著走線怎麼變

時域反射儀（TDR）送出快速的步階訊號，量反射回來的波形，換算出沿路每個位置的阻抗。連接器、過孔、焊墊的阻抗不連續會變成曲線上的凸起或凹陷，時間軸可以換算成距離，用來定位問題點。

VNA 與 S 參數

向量網路分析儀（VNA）在頻域量通道特性，得到 S 參數。高速差動通道常看混合模態參數：

參數名稱看什麼
SDD21差動插入損耗通道衰減多少，愈接近 0 dB 愈好
SDD11差動回波損耗反射有多大，愈負愈好
SCD21差動轉共模P/N 不對稱造成的模態轉換
NEXT / FEXT串音相鄰通道耦合過來的能量

S 參數檔（Touchstone 格式，.s4p 等）也是去嵌入與通道模擬的輸入。

BERT 與接收端測試

發送端測試看的是「送得好不好」；接收端測試看的是「收得住多差的訊號」。位元錯誤率測試儀（BERT）會產生刻意劣化的壓力眼，加上指定的 RJ、正弦抖動（SJ）、ISI 與雜訊，送進待測物，再讓待測物進入迴路回送（loopback）模式把收到的資料送回來比對，計算錯誤率。

等化

高速介面靠等化補償通道損耗，量測時也必須套用規格指定的參考等化器，否則眼睛可能完全閉合。

  • 發送端 FFE / 去強調（de-emphasis）：在發送端預先壓低低頻成分，相對提升高頻。PCIe 3.0 以後定義了多組預設值（preset）。
  • CTLE：接收端的連續時間線性等化器，提升高頻增益，但也會放大高頻雜訊。
  • DFE：決策回授等化器，依據已判斷出的前幾個位元扣除 ISI，不放大雜訊，但錯誤會連鎖傳遞。

各介面的驗證重點

USB

  • USB-IF 相容性測試分為發送端、接收端與線材測試。
  • Type-C 可正反插，兩個方向都要驗證；還要注意低頻週期訊號（LFPS）和 USB 2.0 訊號品質。
  • USB4 需考慮與 Thunderbolt 的相容性。

PCIe

  • 使用 PCI-SIG 的 CBB（主機板測附加卡）與 CLB（附加卡測主機板）治具。
  • Gen3 起要測多組發送端預設值（preset P0–P10），並用 PCI-SIG 的分析工具套用參考 CTLE / DFE。
  • 參考時脈（REFCLK）的抖動也是獨立測項，常被忽略。

HDMI / DisplayPort

  • 須通過授權測試中心的 CTS 項目，並測試不同長度線材下的表現。
  • FRL 與 UHBR 速率下，連結訓練（link training）與等化設定會直接影響結果。

DDR

  • 雙向匯流排，讀和寫的波形混在一起，要靠 DQS 與 DQ 的相位關係或前導碼（preamble）分離讀寫。
  • 重點項目：建立與保持時間、DQS–DQ 偏移、過衝與下衝、VIH / VIL。
  • DDR5 定義了接收端眼圖遮罩與參考 DFE，量測要套用。

高速乙太網路

  • 通道評估常用 COM（Channel Operating Margin），把 S 參數、串音與參考接收器一起算出裕度。
  • 電氣介面看 SNDR、階位線性度；光模組則看 TDECQ。

05 · Workflow

驗證流程

多數驗證專案的時間不是花在量測，而是花在準備和除錯。照順序做好前面的步驟，後面會省很多時間。

  1. 讀規格與測試規範找出規格書、相容性測試規範（CTS）與儀器廠的量測方法說明（MOI）。確認測項、判定標準、所需頻寬與治具。
  2. 規劃測試矩陣列出要測的埠、通道、速率、等化 preset，以及電壓與溫度的邊界條件，估算所需時間。
  3. 準備儀器與校正確認儀器在校正有效期內，開機暖機後執行自我校正、探棒補償與通道 deskew。
  4. 治具與去嵌入準備治具與其 S 參數檔，確認線材狀況，設定去嵌入或參考通道嵌入。
  5. 執行量測並完整記錄用自動化軟體跑測項，同時記下板號、韌體版本、儀器設定與環境溫度，讓結果可以重現。
  6. 判讀與除錯失敗項目先排除量測本身的問題，再往設計、元件或韌體設定追。
  7. 撰寫報告附上結果、裕度、截圖、設定檔與未解問題清單，讓設計團隊能據此決定下一步。

    常見問題排查

    測試失敗時，先懷疑量測，再懷疑設計。下表依症狀整理常見原因和查法。

    症狀可能原因怎麼查
    眼高不足通道損耗過大、發送振幅設定低、等化設定不合適量 SDD21 看奈奎斯特頻率損耗；掃過不同 preset 與 CTLE 設定
    眼寬窄、抖動大參考時脈抖動、電源雜訊、串音做抖動分解，看 PJ 的頻率是否對應電源或其他時脈；量參考時脈相位雜訊
    波形有台階或振鈴阻抗不連續、過孔 stub、端接不當用 TDR 定位；檢查背鑽與端接電阻
    每次量結果都不一樣探棒地線過長、未 deskew、CDR 設定錯誤、記錄長度不足重做校正與 deskew；核對 CDR 迴路頻寬與規格設定
    共模雜訊大P/N 長度不匹配、佈線不對稱、參考平面斷開量 P/N skew 與 SCD21；檢查走線是否跨越平面分割
    連結訓練失敗或降速接收端裕度不足、等化協商失敗、參考時脈問題用協定分析儀或晶片的連結狀態紀錄，看卡在哪個狀態
    只在特定溫度或電壓失敗裕度不足，邊界條件下崩潰在溫箱中做參數掃描（shmoo），找出失效邊界
    只有某幾片板子失敗製程變異、元件批次、組裝問題比對好壞板的 TDR 與阻抗量測；X-ray 檢查焊點

    除錯的基本原則

    • 一次只改一個變數，否則不知道是哪個改變起了作用。
    • 找一片已知良好的板子當對照組，差異往往就是答案。
    • 先確認量測鏈：同一條線材、治具和儀器，量已知良好的訊號源是否正常。
    • 把問題縮小到頻率：抖動或雜訊有特定頻率時，通常能直接對應到某個電源或時脈來源。
